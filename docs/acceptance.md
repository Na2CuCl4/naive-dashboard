# MVP 验收清单

完成结果与具体命令在实现后填写到 validation.md；未实测项目不得标记通过。

- [x] 固定工具链、fork HEAD、模块锁与隔离 Caddy 构建；生产进程/二进制未替换。
- [x] 管理员登录、退出、CSRF、未登录拒绝、稳定错误码、双语键完整和语言切换。
- [x] 创建/编辑/禁用/删除用户、授权/撤销、代理凭据和订阅 token 独立轮换。
- [x] 订阅只输出有效授权节点，URL 编码正确，额度/到期禁用，旧链接轮换失效。
- [x] SSH 指纹不匹配拒绝、私钥路径受限、固定 RPC、超时、不输出敏感参数。
- [x] 配置版本幂等、零用户认证拒绝、候选校验失败不修改、reload 失败恢复、重启中断恢复。
- [x] 短连接最终事件、活跃一分钟快照、双向相同计量层、并发/重试/重复/乱序差额、旧身份结算。
- [x] reload 旧隧道、进程重启 epoch、游标持久化、尾部半行/截断错误、跨月增量。
- [x] 额度达到后撤销、离线节点待同步、健康和采集延迟可见。
- [x] Docker/Compose 构建、隔离本地节点接入、HTTP smoke、容器重建持久化。
- [x] HTTP/2、HTTP/3协议级 reload/复用撤销行为已验证（见 validation.md）。
- [ ] 用户实际原生 Naive HTTPS/QUIC 客户端与生产构建端到端验收：环境未提供，不声称已通过。
